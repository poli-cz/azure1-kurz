# Terraform: jedna resource group

`main.tf` vytvoří resource group `rg-terraform-demo-<náhodné číslo>` ve West Europe a vypíše její název.

```
terraform init
terraform plan
terraform apply
terraform destroy
```

Celý postup včetně instalace a přihlášení: [postupy/05-terraform-na-vm.md](../../postupy/05-terraform-na-vm.md).
